# Security policy

Please do not post potential vulnerabilities in public issues or include target credentials, private reports, or personal data in a public discussion. Once the GitHub repository is created, use GitHub's private vulnerability reporting feature if it is enabled; otherwise contact the repository owner through a private channel. Include the affected version, impact, and a minimal reproduction. Do not test against systems you do not own or have permission to assess.

This repository is a localhost research tool, not a managed security service. Its third-party observations and generated reports are not verified vulnerability findings.
